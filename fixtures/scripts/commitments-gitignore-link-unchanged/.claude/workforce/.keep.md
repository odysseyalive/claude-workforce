Fixture marker. The case's `git` block creates `.gitignore` beside this file as a SYMLINK to
`decoy.md` at the top of this tree, and asserts that file's bytes are unchanged afterwards.

THE LINK IS MADE AT RUN TIME, NOT CHECKED IN: git refuses to follow a symlinked `.gitignore`
and warns `Too many levels of symbolic links` on every command that walks past one, so a
tracked link at that name would put that warning in front of every maintainer forever. The
harness's `links` key exists for exactly this.

The ignore rule rides the ledger write, so it is appended by a hook that runs on every turn
with nobody watching, at a path anyone who has seen one workforce project can predict. An
append follows a link, so a link planted at that name sends the note and the rule wherever
it points — in a real project, a file outside it. `os.path.islink()` and then `open(p, "a")`
resolve the name twice and lose the race (CWE-59); the open itself has to refuse, which is
what `O_NOFOLLOW` does. The ledger must still be written: refusing the rule is not refusing
the turn.
