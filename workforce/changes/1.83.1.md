Resumed agents: a hand-back ends the round, and a finished agent no longer holds its role

From odyssey-alive (2026-10-30). The final budget notice was attached to an
agent's own SubagentHandback call, so it reached the next order and the agent
obeyed it: a re-review stopped after 2 calls. A hand-back now gets no notice and
ends the round, so the parent's next prompt is a fresh allowance; a message
mid-run still opens nothing. Skill-load and image rows (sourceToolUseID,
turnCompanion) are never read as a resume.

The spawn guard held a business-analyst that had handed back PASS, because the
order's `.../OUTPUT.md` path did not resolve and the stop was read as a cut. A
stop whose last call is a non-HANDOFF hand-back is not a cut. The turn-cap PERF
now says the agent handed back on its own and names a report left in its
worktree, instead of "stopped at turn 40 of 40".
