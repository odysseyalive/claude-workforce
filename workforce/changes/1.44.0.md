The judge is not the one who did the work (v1.44.0)

IMPLEMENTS the two directives captured in 1.43.0: "Evaluations are always done by the
independent agent", and "you have to measure results, not measure what you're doing
and it has to be aligned with the current request."

THE SCORE IS GONE. `wf-widen` no longer returns 0-100 and `WF_WIDEN_THRESHOLD` is
retired with it — a threshold implies a scale, the scale was invented, and a dial on
an invented number is a second invented number. What dispatch reads now is a FACT: a
channel the ask required recorded zero calls. `taste 0` is a count against zero;
`100/100` was a grade nothing computed.

THE HAND-OFF CARRIES THE THREE THINGS A RESULTS JUDGEMENT NEEDS — `ask` (what the user
requested and how it was tagged), `evidence` (which channels the turn opened and how
much), `conclusion` (what it told the user). The agent prompt no longer says "open the
named channel"; it says judge whether the evidence supports the conclusion FOR THAT
ASK, and verify it against the repository rather than taking the turn's word.

PASSING TURNS ARE AUDITED TOO, at `WF_AUDIT_SAMPLE`, default 1 in 5. Auditing only the
turns that fail their own dispatch is the self-scoring bias one step removed: a turn
that looks fine would be judged by nothing but the session that produced it, and
looking fine is exactly what a tunnel does from inside. `1` audits every
claim-carrying turn, `0` disables sampling. Deterministic per reply, never random, so
a run reproduces and a fixture can pin it. A sampled turn is reported and NOT blocked —
it opened every channel its ask required, so this hook has nothing to object to.

The rate was DECIDED rather than asked. It is a cost dial the user can change without
editing code, and parking a build on a reversible number is the shape the user has
twice told me to stop.

THE SIXTH SENSE IS UNLOCKED, not by new code but by the directive. `intuition` shipped
permanently unscored because judging one's own prior from inside is the impaired
faculty — true, and it only ever ruled out SELF-judgement. The agent did not form the
prior and can read it. It was unmeasurable because of an architecture flaw, not because
of anything about intuition.

THREE BUGS FOUND BY RUNNING RATHER THAN READING:

A silently disabled guard. The first patch replaced `senses()`'s docstring and left its
BODY returning the old score, so `unopened, rows = senses(...)` unpacked a number into
`unopened` — and a score of 0 is falsy, so the hook stopped blocking entirely while
reporting "required channels opened". Caught by testing a turn that should have blocked.

A redesign that reached nothing. `--wire-defaults --execute` reported `wf-widen-agent`
"already registered — NOOP" after its prompt was rewritten from "open the channel" to
"judge the evidence" — the entire point of the release. An agent hook IS its prompt,
and identity is deliberately coarse (a marker, so a rename cannot orphan a live
registration), so equality has to be checked separately or a rewritten prompt reports
NOOP forever while the machine keeps running the old one. Found by reading
settings.json instead of trusting the word NOOP. It now updates in place, verified by
re-read, and the second run is a clean NOOP.

An assertion tripping on its own prose. The new check forbids "/100" appearing in
`wf-widen` — and that file explains at length why the score was removed, so it
necessarily contains the string. Third time this shape has bitten here, so it is
stripped properly rather than special-cased: docstrings and comments out, then match.
