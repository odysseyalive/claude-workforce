wf-conform: the reported length floor is one a handbook can stand on

`_ic_floor` subtracted every line of Scope, Sources, Procedure and Verification —
relocating all four to ZERO — and the docstring called the result "the shortest
the handbook can get by relocation". `SECTIONS` in this same file MANDATES three
of those four, and Core Principle 3 keeps the runnable check in the handbook, so
a body that reached the number would fail this script's own section row. It
reported an unreachable target as a reachable one, to an author who is being
told to trim toward it.

The customer who found it would not file it, because they could not separate
design from accident. It separates mechanically and needs no judgment: the
computation deletes sections the script requires.

THE SECOND CONSEQUENCE IS THE WORSE ONE AND IT IS NOT ABOUT PROSE. The caller
enters "no relocation is ordered: it cannot reach the target" only when the
floor still exceeds the ceiling. An understated floor makes that branch fire too
RARELY, so a handbook that cannot reach the ceiling is ordered to split anyway —
the exact 1.61.0 defect the unreachable row was built to end, still live in the
arithmetic underneath it. The reported number was the visible half.

A relocated section now keeps its RESIDUE: the heading `SECTIONS` mandates, one
pointer line naming where the content went, and for `## Verification` the
`Check:`/`Negative:` lines as the file actually carries them — the one content
that cannot relocate anywhere. Counted from what this script demands, never
estimated.

Scale, on a synthetic 24-line handbook: 7 before, 15 now. On the customer's
`platform-security-evaluator` the floor moves 181 -> 189 and the VERDICT does
not — unreachable at both — which is why that fixture records the correction as
a number rather than a different outcome. `conform-over-ceiling`, the reachable
half, still gets its order, so nothing flipped the wrong way.

Also fixed here: the new assertion imports a shipped script, and without
`dont_write_bytecode` it dropped a __pycache__ into workforce/bin/ that the
manifest check correctly reported as an undeclared shipped file.

Proven by making it fail: the old zeroing computation was restored and the new
check fired by name, with the conformance suite catching it independently.
1399 checks pass, 310/310 conformance.
