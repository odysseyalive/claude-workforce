Plan-only in auto mode, and the contracts six cold reads found

`/blueprint` authors an implementation plan as a FILE and stops there. Plan mode
is a permission state, so it blocks writes and turns every read into an approval;
this is instructions, so it works in whatever mode the session is already in. The
cost is stated in the skill rather than hidden: nothing mechanical holds the
plan-only contract, and the four rules are the whole of it. Ships as a `sibling`,
so `update` alone carries it. Proven by installing a throwaway tree and finding
it at `<config-root>/skills/blueprint/`.

Its manifest block first repeated `AUTHORED HERE, NOT VENDORED`, a literal
`bin/check:2899` pins, which made that assertion VACUOUS: breaking the original
block no longer failed it. Reworded, re-proven by breaking it on purpose, and the
comment now says why not to restate that heading.

`wf-conform` gains two ADVISORY rows over governed handbooks. Both came out of
building this project's first org, where four cold-read probes failed on defects
nothing could read mechanically:

  probe substitution-table coverage - the table closes with "No clause of any
  other section is left for you to interpret", and a table missing one row is a
  promise the document breaks, paid by the reader as a burned probe cycle.

  exit criteria restating a value - where the section's own preamble says it
  never restates what a condition means, a bullet that states one instead of
  citing its owner. The measured instance had already DRIFTED: the owning step
  governs "a shipped file", the bullet had narrowed it to "every new shipped
  file", silently exempting a file whose tracking breaks by rename.

Both ADVISORY on this file's own recorded reasoning: they parse free-form table
prose, so a compliant table phrased differently scores uncovered, and a detector
that fires where the fix cannot run is worse than silence. Each is pinned by a
`bin/check` assertion and each was proven by breaking it. The first regex shipped
cubic ReDoS (21s at 3,200 chars) and its first fix was still super-linear, since
`\s` and `[ \t]` are subsets of ``[^`\n]``; the shipped form carries one repeat
operator.

Seven `script-conformance` fixture trees were declared in `expectations.json` and
never committed, so those cases failed on every fresh clone while passing here.
Same class as the `wf-seed` defect `bin/check` already guards for manifest files,
one directory over.

README: the hooks paragraph rewritten, `/blueprint` documented under Quick start,
`Quick Start` renamed `How to Use`, and the shipped-skills list corrected from
five to six. Two pre-existing em-dashes removed.
