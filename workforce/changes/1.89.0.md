wf-task-tag's dispatch line to hand its job to a background subagent and
did not. Every project edit ran inline through Bash heredoc writers and
sed -i, and six foreground Bash calls (520000-920000 ms timeouts) left the

main session only (a payload with agent_id returns at once):

  denied, naming the background re-issue or a background subagent;

  tool or by a Bash writer, is denied once; the retry passes. The reason
  names the org's employee, or a plain general-purpose subagent with no org.

outside the project are never denied. Fails open on error.

Replay over 361 transcripts: 692 long-foreground denials, 224 deny-once
turns, all read, 0 wrong fires after the outside-path rule.
