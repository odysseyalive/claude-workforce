The class that needed a human: a true citation supporting a false claim

The first trigger catches a claim made with NO evidence. It misses the failure
that actually required correcting, because that turn read plenty.

"Vendor is the only documented path for a remote repo" cited scopes.md:140 and
update.md:41. Both true. Both ABOUT VENDOR. The claim was about the SPACE OF
ALTERNATIVES, and no read enumerated that space — README.md's published one-liner
was never opened. The citation's scope did not cover the claim's scope, and that
is invisible to any check that asks whether a citation exists.

THE MECHANICAL DISTINCTION, and it needs no judgment:
  POINT read  answers "what does X say?"       Read(file), grep for a known term
  SET read    answers "what is the set of Y?"  Glob, find, ls, grep -rl, a census

A universal claim is a claim about a SET. Point reads cannot support one however
many there are — that turn had three.

RATES over 1,497 substantive Opus 5 turns:
  a universal claim anywhere              28.7%
  ...with no set-read in the turn          2.1%
  ...and not inside quoted text            1.5%   <- shipped

The quote exclusion is not tidiness. Without it the trigger fires on a turn
DISCUSSING such a claim rather than making one — common in exactly the sessions
where it would be read, and the first measurement (5.5%) was inflated by it plus
two over-broad phrases.

Verified four ways: it fires on the real vendor turn; goes silent when the same
claim comes from a turn that enumerated; silent when the claim is quoted; silent
on point reads with no universal claim.

WHAT IT CANNOT DO, in the reference so no report can overclaim it. ProvenanceGuard
(arXiv 2606.18037) measures source-attribution accuracy falling to 0.229 with
semantically close sources, and two files in one repo are close. This flags that a
set-claim rests on point reads. It does NOT establish which source should have
been consulted.

Two triggers now, covering two different failures: no evidence at all (0.5%), and
evidence of the wrong shape (1.5%). Both report, neither blocks.
