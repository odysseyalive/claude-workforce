The largest measured defect was the one nobody had counted

MEASURED over 4,447 real Opus 5 replies from this machine's own transcripts, by
the four classes the user's own complaints define:

  undecoded jargon          7.0%   "too cryptic... I don't understand what you're asking"
  causal claim on absence   2.9%   the three failures that started this
  handing work back         1.2%   "are you going to fix it, or just telling me?"
  caving opener             0.3%   "you're right... now that you mentioned it"

Jargon is more than double the class the whole day's design work was aimed at, and
twenty times the one that got its own directive. It is also the one the user has
complained about more than once. Nothing had ever counted it.

WHY THIS IS NOT THE GUARD THAT DIED. wf-speak-guard fired on 7.0% of GOOD replies
because it matched ordinary English — "wrong", "failed", "gap" (changes/1.30.1.md),
and its removal is asserted so it stays removed. This matches only words this
project INVENTED: `rung 10`, `the pool`, `emitter`, `dormant`, `INV-…`, `ORG-RECORD`.
They have no ordinary meaning to false-positive on, so a fire means the term is
genuinely there — and it reports rather than blocks, naming the exact term, so the
remedy is unambiguous.

CODE SPANS ARE MASKED, and that came from measurement rather than caution.
Unmasked the rate was 7.0% and every false positive was one shape: `dormant` inside
a probe FILENAME, `fan-out` inside a table cell of identifiers. Masking dropped it
to 5.2% and took the whole class with it. A backticked term names an artifact; a
bare one asks the reader to decode it first.

FOLDED INTO wf-turn-ledger rather than shipped as a second hook. One Stop event,
one transcript read, one line. Every additional always-on mechanism is another
thing that can go dormant, and this project has paid for that three times. The
read count covers whether a turn was grounded; the jargon scan covers the thing a
read count cannot — a turn can be perfectly grounded and still hand the user a
sentence they have to decode.

Three fixtures, including the false-positive class as an explicit silent case.
