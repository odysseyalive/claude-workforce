An update that finished still read as broken, and eight hooks died quietly

`/workforce update` closed by telling a repo with no employees that its update
was not complete, and to run `audit` — on the workforce distribution, which the
Self-Exclusion Rule forbids auditing. Both halves were defects, not misreadings.

update.md step 7 named `audit` on any heal-flagged release with no census of
whether the project HAS an org. It now reads `.claude/agents/` first and states
all three outcomes, including the one where naming `audit` is forbidden. A
bin/check assertion holds the census in place.

bin/sync listed the in-project path as a target unconditionally, so `--personal`
— asked for one copy — rebuilt a 137-file install the user had deliberately
deleted. `update.md` § Resolution rules had stated the rule since the beginning
("update never creates an install that was not already there") and every
maintainer path was exempt from it. Sync now refreshes a project install only if
it is already there, and says so when it is not.

bin/dev-sandbox is new: a throwaway install under $HOME via CLAUDE_CONFIG_DIR,
removed in a `finally` block so a failing command, a traceback and a Ctrl-C all
clean up. Testing against the live personal copy — which every other project on
the machine resolves, and a peer session may be running against — is not a test
environment. Both user messages are recorded verbatim in § Directives.

THE EIGHT DEAD HOOKS. The three-paths directive built three paths for WIRING a
mechanism and none for UNWIRING a retired one. The 1.30.2 strip cut the shipped
hook set from nine to one; updating removed the scripts as designed and left all
eight registrations in ~/.claude/settings.json pointing at paths that no longer
exist — run every turn, failing every turn, invisibly. `prune_dead_hooks` rides
`--wire-defaults`, the single producer the installer, `audit` and `verify` all
call, so it reaches every path the wiring reaches and needs no fourth gesture.
Matching goes through `_same_command`, so a hook spelled with `$HOME` is not read
as a missing path and pruned while live.

bin/check grows a third outcome. Four assertions read a project's own org state,
which this repo does not carry, and they were red for that reason alone. SKIP is
not a pass: `read()` returns "" for an absent file, so `"x" not in ""` is True
and an unstaffed repo would have reported every one of those rules upheld having
measured nothing. Skips print their own section with the precondition that would
evaluate them, and the guard/assertion pair skips together or runs together.

bin/prove crashed on the first case naming a deleted script, taking every other
case down with it; it now reports STALE-CASE per row. 84 such rows are removed,
and three in bin/idempotence. The idempotence sync case is seeded, because a
writer that refuses to create what is not there otherwise compares two empty
trees and reports green having measured nothing.
