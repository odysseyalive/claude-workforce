Fix nine defects a customer audit found on a RHEL 8 host

Reported by the nc-audit session after `/workforce audit` on the Nevada
Classics project (workforce 1.59.1, cPanel jailshell, RHEL 8, system
python3 3.6), plus one reported by the user the same day. Every item was
re-verified against 1.60.1 before it was fixed, and every guard below
fails on the pre-fix tree.

1. Python 3.6. wf-preflight and wf-apply crashed on
   subprocess.run(capture_output=, text=), and wf-widen's fromisoformat
   raised inside a swallowed except, so a check stopped working silently.
   MEASURED in a real python:3.6-slim container: those three were the
   only 3.7+ uses in 25 shipped scripts. The floor is stated once,
   PYTHON-FLOOR: 3.6 in platform.md, and bin/check walks every shipped
   script's AST for 3.7+ APIs.

2. The Strategic Objective was still the template placeholder at the
   first cold-read probe, because no audit step drafted it, so a Lead's
   probe failed against text nobody had written. audit.md Step 1c now
   drafts it from the survey, never asks, and reports it for the user to
   overturn; `wf-companion --objective / --draft-objective` detects and
   writes it. The draft is NOT written inside an
   `origin: user | immutable: true` span, because that marker means the
   user wrote the words. A placeholder at probe time is a failed run
   precondition (UNAVAILABLE), never a DEF against the handbook
   (SKILL.md failure-attribution gate item 9).

3. `wf-remainder --swept-refs` counted history inside a data skill's
   records as LIVE, which data-skills.md forbids editing, so the scan
   could never reach 0. A new RECORD bucket, recognized from the skill's
   own declared ## Schema, never guessed from a directory name.

4. wf-conform read DEF records from personnel/defects/, while the schema
   says personnel/ is flat, so the Class-fix check checked nothing and
   passed. It now reads flat, still reads legacy subfolders and reports
   them, and prints its count including zero. Turning it on showed 110
   of 126 historical DEFs on this machine lacking a Class fix, which no
   mechanism can supply, so at verify it is a counted advisory. It
   BLOCKS where a DEF is written: `wf-conform --def <path>`, defect.md
   step 5d.

5. wf-stamp stamped four directories while wf-conform demanded every
   sacred block under .claude/, so an archive copy under
   .claude/workforce/migrated/ was required and unstampable. Both now
   call one function, wf-census sacred_scope(), and bin/check runs both
   on one tree to prove they agree.

A. The tier canary has had no instrument since 1.31.0 removed the
   registered fixtures (they appeared in every session's agent menu), so
   C2 returned UNAVAILABLE on every run. `wf-apply --run-canary` defines
   the canary agents through `claude -p --agents`, which exists for one
   headless session and writes no agent file. MEASURED on 2.1.268: the
   revoked IC is denied Agent 6 of 6, the control is granted it 6 of 6
   (measurements/2026-09-15-agents-flag-canary.md). Every procedure that
   wrote fixtures now runs the runner.

B. The harness refuses a subagent Write whose basename matches
   /^(REPORT|SUMMARY|FINDINGS|ANALYSIS).*\.md$/i. Read from the 2.1.268
   binary (platform.md fact 25). Warned where handbook outputs and probe
   work products are authored; bin/check runs the harness's own regex
   over every shipped file.

C. The IC length advisory ordered a relocation to 172 lines that the
   mandated sections alone could not reach: three customer ICs sat at
   297/231/296 after relocation. The row now prints a per-section
   breakdown, does not charge conform-mandated lines to the author, and
   orders nothing when the required content alone exceeds the ceiling.
   procedure-for-procedures.md records that 172 is one IC's measurement,
   not a floor for every IC.

D. Setup questions reached the user in reverse. The run issued the
   calls in spec order but several in one message, and the UI answered
   them newest-first (model B, model A, backup; effort B, effort A),
   inferred from answer timestamps in the customer transcript. Each
   setup call is now the only tool call in its message, INV-BUDGET
   reports order as well as count, "pre-selected" is defined in terms
   AskUserQuestion can render (an in-pool current value is a label in
   its cost position, never promoted), and the stale "questions 3 and 4"
   ordinal is corrected.

Heal for existing hosts: the shared data-skill definition would have
turned one host red with no path back, so wf-companion now heals a
customized personnel-ledger by appending only the sections it lacks
(original bytes kept as an exact prefix), and audit Step 3b drafts a
project data skill's missing contract section from its own records.
