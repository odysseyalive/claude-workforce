THE ANTI-BLOAT INVARIANT. Every accumulation defect found in this repo today turns
out to be one shape: a producer nobody reads. Four inherited hooks that never
fired. Nine advertised commands with no procedure. Eighteen `read()` calls against
files that do not ship. 107 prove cases naming deleted scripts. And, three hours
after removing four separate instances of it, `wf-turn-ledger` itself — wired into
SHIPPED_HOOKS and the manifest while ZERO markdown described it and no assertion
touched it.

So it is an invariant rather than a habit: every shipped script must be named by a
reference file AND mentioned by an assertion. The two halves are different
questions — the first is discoverability, the second is enforcement, and a script
can have either without the other.

and its own long comment names `wf-turn-ledger` while explaining that
wf-turn-ledger has no assertion. The check reported the defect fixed by describing
it. Caught by asking why it went green rather than accepting the green; comments
are now stripped before the assertion half is tested. That is the third instance
today of a guard satisfied by its own prose — after the `^.*$` wildcard that
cancelled the orphan-case check, and KNOWN_COMMANDS derived from the line it was
checking.
