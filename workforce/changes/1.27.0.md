Presence is not runnability, and reading is not running (v1.27.0)

Six defects reported by a live `/workforce audit` on another project, then nine
more from four cold reads of the repair, then two only a real run could find.
Every one reproduced here before it was touched.

WHAT THEY SHARED. Each sat behind a check that asked whether a string was
PRESENT — the right question for "did the section land", the wrong one for "can
what landed be RUN". Both print the same green line. `wf-conform` confirmed the
handoff boundary clause present in five handbooks while it named a command that
exits 127.

THE REPAIR HAD THE SAME DEFECT ONE LAYER DOWN. `--self` compared the post-shell
`" ".join(sys.argv)` against a transcript that records the command AS TYPED, and
the clause tells the reader to type a tilde path with a quoted root — so it
exited 2 before printing any verdict and the clause's next four sentences
described output that never appears. It moved from 127 to 2. It survived because
`--self` had never run: no fixture, and no invocation in any recorded store.

- wf-handoff: the clause defines its trigger in terms the reader can SEE (verdict
  in hand AND OUTPUT.md on disk), carries an absolute path, states every branch
  including the one where no verdict prints, and sources `--brief` from the
  printed line. `--wire` REFRESHES a clause it wrote under an older wording and
  reports refreshed/stale/current separately; `--unwire` reverses a superseded
  wording and still keeps a human edit, by the sha it recorded. `--self` matches
  the typed command via shlex, requires the union of both keys to hold ONE agent,
  and `--as <employee name>` confirms against something the caller knows about
  itself. `--out` writes the brief instead of leaving the reader a redirect to
  invent. Completion notices are read from every transcript that carries them,
  not only the session file.
- wf-checkrun resolves commands wired into `## Guardrails`, not only
  `## Verification`; wf-conform diffs org-chart edges both ways, detects
  self-parenting, and stops applying an IC-measured ceiling to Leads;
  wf-settings-apply matches hook commands after expansion and reports
  double-firing; wf-remainder tests its insertion anchor against sacred spans.
- platform.md: fact 23b's "one hit, unambiguous" was measured with ONE agent and
  carried a design that only runs with several. MEASURED now carries the
  conditions it was measured under, and a claim about a relationship must name
  the tiers it was measured between — three instances of one shape in one day.
- org.md rung 12b: a returned HANDOFF spawns a successor. It had no consumer
  anywhere, so an agent could complete every step the clause asks and nothing
  downstream was told to act.

bin/e2e-handoff EXECUTES the chain rather than asserting about it, and found on
its first run what four reads had missed: the printed follow-up carried `--root`
but not the `--transcripts` that resolved the store, so the command the clause
says to run exactly as printed could not find it.

bin/check gains 30 assertions; bin/prove 34 cases and two guards — an absent or
already-present payload mutates nothing, and a case name must BE the name of the
check it breaks (43 cases were unattributable paraphrases, proving nothing while
looking fine).
