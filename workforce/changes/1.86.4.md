Every turn that starts from a worker's report gets a juror, and a finished agent no longer blocks a new spawn

A main turn opened by a hand-back or task notification that has no
docket and trips no claim now seats sight and intuition every time,
seat-only. A reply that is only questions, or only a claim-free hold, is
excused. Measured over 1,332 mutze Stops: +11.2 seats per 100 Stops; on
mutze 30e77777 Stop 614 now seats.

The spawn guard falsely refused a new engineering-coder after the last
one had handed back PASS: that stop came on a continuation, and
ledger_verdict returned before recording the agent's return, so its
`handoff` mark stood. Agent stops are now recorded on continuations, and
held_by reads only the current issue. A real cut on the same issue is
still refused.

User decision: "Build it (Recommended)" - "Every turn that starts from a
worker's report gets a juror, even when nothing else triggers one."
