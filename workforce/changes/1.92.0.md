A rule kept in Claude memory is caught and applied in the project: principle 15, wf-memory, reconcile-memory

The user, 2026-11-26: memory items "stashed where they can't be accessed by any account"
must be "'caught' and applied correctly within the project scope", and "the audit should
use that skill". Memory belongs to one account; the project's files reach every account.

Principle 15 (templates.md WF-PRINCIPLES, digest in principles-history.md): a rule the user
sets, or one recalled from any memory store that the project lacks, is applied in the
project that turn: an existing file first, then a handbook AMD, a skill, a script or hook,
a new principle last. user-type memory stays personal. Memory entries may stay.

wf-memory (new, two default hooks, never blocking): at an Edit/Write/MultiEdit under any
~/.claude* or $CLAUDE_CONFIG_DIR projects/<store>/memory/ for this project or a parent
folder, a rule entry not already recorded gets a note to apply it now through the skill.
At SessionStart every rule in any account's memory (ancestors included) whose content hash
is not in .claude/workforce/carried-memory/ledger.json (gitignored) is named; identical
copies across accounts are one rule, a changed entry is uncarried again. This replaces an
account-switch detector. Modes --scan, --record (--home | --left), --backup. It cannot see
memory the service holds without a file; the principle and the skill's in-context pass do.

reconcile-memory (new sibling skill): the one implementation. Scan, add the rules the
session recalls, find each rule's home searching the project first, show a table, back up
and apply on yes, record. Audit Step 6-K calls it (survey reads --scan; consent names it;
--review lists only).

Handoff: the writer no longer asks which account picks up or syncs memory to it; the
section becomes ## Pages plus "any account picks it up". Pickup compares WORKFORCE-VERSION
and names /workforce update, and runs reconcile-memory on a MEMORY RULES line.
wf-account-sync no longer copies memory (its only caller was the handoff); it keeps the
install copy and hosts the config-dir/store-name lookup wf-memory imports. Ten account-sync
fixtures updated, five wf-memory fixtures added, rewire-noop fixture gains the new rows.
