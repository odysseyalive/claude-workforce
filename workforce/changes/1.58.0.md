Fix 16 defects from two TicketTomato audits, plus dead-gate and detector cleanup

Two live audits (runs audit-20260913T210339Z and audit-20260913T210900Z)
against workforce 1.57.1 surfaced defects in the distribution itself. Each was
verified against source before fixing; every fix ships with a test fixture.

Tool fixes:
- wf-commitments: resolve the ledger root from CLAUDE_PROJECT_DIR, not getcwd,
  so a cd no longer creates a stray commitments.json.
- wf-ratchet: --help/-h prints usage instead of running a no-baseline compare.
- wf-conform: a bare absolute-path argument (e.g. /tmp) in a shell example is no
  longer misread as a /skill invocation (false-positive advisory).
- wf-conform: check_removal_set resolves a swept target's undo from the T8 row's
  recorded path (work/<run-id>/staging/...), not only the mid-run staging dir, so
  a correctly-swept employee is no longer flagged forever (DEF-Q-002).
- wf-ledger: index --execute preserves org-family one-line summaries instead of
  rewriting them to bare rows.
- wf-stamp: Lead/CEO judgment-tier handbooks report N/A, not the alarming
  NO-SECTIONS, since they intentionally carry no Procedure/Verification contract.
- wf-apply: detect_stale_canaries compares MEASURED-ON to the running harness
  instead of gating on the mere presence of TIER-LIMIT, so it no longer deletes
  fixtures a run just wrote (DEF-Q-006).
- wf-catalog: dedupe the hook-registration path list by realpath (no double-count
  at a $HOME-rooted project); walk up from cwd to the nearest .claude/ so a
  catalog read survives a cd, with --execute refusing an inferred root; recognize
  a single copy as the install under scope collapse (DEF-Q-007a/c, DEF-Q-010).
- wf-settings-apply: check hook presence across the union of applicable settings
  files and collapse user/project when they share a dir, so already-wired hooks
  are not offered again (DEF-Q-007b).
- wf-remainder: maintainer-only bin/ references are not flagged as dead scripts
  (bin/ does not ship) (DEF-Q-009).

New detectors (user-approved):
- wf-conform: cross-handbook ownership-conflict check and self-contradictory-write
  check, each with false-positive guards and fixtures.

wf-widen Stop-hook (the missing "done" signal):
- On SubagentStop, judge a subagent on its own transcript alone; never mix the
  parent's evidence or the session's ask into a subagent's verdict, and never
  raise a main-turn flag from a subagent stop.
- Gate the whole Stop decision on pending or just-finished background work, so a
  legitimate wait between agent batches is not read as stopped-mid-work.

Docs:
- platform.md: document claude-opus-4-8 effort rungs (fact 12d); reconcile stale
  analytical-lane model text in org-config.template.md (DEF-Q-009 budget gap).
- audit.md Step 5d item 2c: all five resolvable catalog kinds (text, code,
  security, image, ui) are healable, matching wf-catalog and wf-conform.

Integrity and dead gates:
- Wire bin/check's sacred-block drift comparison into a live check(), and refresh
  workforce/.immutable.sha (SKILL.md Directives, templates.md principles) which had
  gone stale since v1.26.0 while nothing read the stamp.
- Remove the orphaned _drift_problems gate that shelled out to the removed
  wf-effort-budget against a nonexistent fixture tree.
- bin/script-conformance: honor must_not and reject expectation keys and fail on
  any unrecognized key; this closed three long-standing companion-* failures and
  fixed two wf-companion defects (a docstring exit-code contradiction and a
  fabricated invariants.md quotation).
