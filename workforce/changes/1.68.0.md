Finished teammates are shut down, and work orders name only tools the runner holds

spawned for that order and records `closed:` on the spawn edge (org.md 6g);
review counts edges that never closed. One-shot work prefers plain subagent
spawns. An order names only tools in the callee's tools: minus disallowedTools:.
An IC told to use a tool it lacks says so and does the work with what it has.
npx runs only a package whose identity is known, never one guessed from a tool
or project name; MCP servers are reached through their tools. timeout is advice
for commands that may wait. ICs and Leads write OUTPUT.md incrementally so a
turn-limit stop still leaves a report. Rules ride wf-task-tag on both the
operator and employee events; audit Step 5d heals them into existing orgs and
