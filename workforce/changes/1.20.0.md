The rule reached the user in the register it forbids (v1.20.0)

The plain-output rule shipped on 2026-09-05 and two days later the user
said "nothing came of it." They were right.

That fix enforced one thing: a word list on AskUserQuestion. The register
they object to lives in REPORTS, and nothing read a report. Its three prose
carriers -- operating-principles item 11, /org rung 13, SKILL.md 8b -- are
each read at the HEAD of a context, so every one was faintest exactly when
a long run was writing its longest report. Same decay the CLAUDE.md
evacuation directive names, arriving at a rule instead of at a file.

And text-eval had the test and excluded the corpus. Conversational register
-- the coffee test, the one written check that fires on formal prose without
waiting for a cluster -- exempted "run deliverables", which is the report
handed to the user. plain-output.md cited that row as its own authority, so
the inheritance had been cancelled at the source.

Two carriers that do not decay:

  wf-speak-guard, a Stop hook. It receives last_assistant_message -- the
  finished reply -- once per turn, forever. An opening agreement BLOCKS; a
  banned term the user has never typed this session, and a long reply whose
  only question sits in its last quarter, come back as additionalContext.
  The word check is scoped to the transcript because a flat list applied to
  a report fires on nearly every reply in a repo whose subject is handbooks
  and tiers, and a guard that fires on everything is one somebody turns off.

  The Plain Speak output style, added to the system prompt, present at full
  strength on turn 200 exactly as on turn 2. It reaches the MAIN
  CONVERSATION ONLY -- a subagent runs its own system prompt -- and every
  surface that names it says so.

The second half of the directive is new and is not about style. It names
caving under pushback: the reply the user quoted opens "You're right", and
sycophantic agreement is measured at 18% once a user has pushed back
against 9% when they have not. So an opener is the one thing the guard
blocks rather than notes, and "never concede because someone objected" now
rides operating-principles and /org rather than living in one reference.
