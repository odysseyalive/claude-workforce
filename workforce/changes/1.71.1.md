A house-rules refresh crashed on every tree that already had a region, and a retirement re-seeded the copy it retired

Two defects in released 1.71.0, both found by running a display-mode script
against a copy of a real project rather than against a fixture.

1. `wf-catalog --house-rules` crashed with `NameError: name 'body' is not
   defined` (wf-catalog:1206). The `current` branch compared against a bare
   `body`, a name bound in `house_write` and nowhere in `house_state`. The only
   way to reach that branch is a tree whose evaluator ALREADY carries a
   WF-HOUSE-RULES region, and every fixture shipped with the producer was a
   first-write tree — so 1,411 checks passed over a read-only call that audit
   Steps 4 and 6-E both make on every brownfield run. Fixtures
   `catalog-house-rules-current` and `catalog-house-rules-stale` enter the branch
   from both sides; both fail against HEAD with the NameError and exit 1.

2. `--migrate` retired `references/text-tells.md` — the file the anchor's
   `additions-seeded` pin named — and left `references/ai-patterns.md` standing
   because live readers cite it. wf-seed's only test for "this copy is retired"
   was an empty directory, so on the next audit `_resolve_target` fell through
   the dead pin to ai-patterns.md and wrote workforce's additions back into the
   copy that had just been retired. Measured on a copy of `university`.

   The retirement is now RECORDED rather than inferred: `--migrate --execute`
   rewrites the pin to `method=retired`, which wf-seed reads exactly as it reads
   `method=mirror` — a copy it reports on and never writes into. The line's
   spelling stays in wf-seed, its owner, and wf-catalog writes it through
   `_sibling`. `--migrate` display names the rewrite before `--execute` makes it,
   and `retired` is now counted and printed in `INV-SEED`, where it had been in
   neither and left a fully migrated project reporting two evaluators the line
   accounted for nowhere.

Fixtures: catalog-house-rules-current, catalog-house-rules-stale,
catalog-migrate-retires-seed-pin, seed-retired-pin. All four FAIL against HEAD's
scripts (4 failed / 351 passed) and pass after (355 passed, 0 failed).
`HOME=<tempdir> python3 bin/check` → 1413 passed, 0 failed.

PRE-EXISTING, untouched: `bin/idempotence coverage` fails at HEAD as well —
`bin/check binds _dsc to two files`.
