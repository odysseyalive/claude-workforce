Heal dead and cross-root workforce hook rows on first use, in every project

A release that retires a hook script left its registration in every project's
settings, failing on every prompt and tool call. `update` pruned only the user
settings file, `verify` only reported, and only `audit` cleaned a project. The
census counted 38 dead rows across six projects on one machine.

The carrier is the SessionStart registration of wf-commitments, already wired on
every default install: the next session opened in any project heals it, with no
audit and no typed command. One rule decides every removal (dead_row_verdict),
shared by the heal, the installer's user-scope prune and wf-apply PASS-DEAD-HOOK:
a row goes only when its script is on RETIRED_HOOKS, its file is missing, and the
install that should hold it is complete. A shipped name is never removed.
Retired names are reserved forever and the list is cross-checked against git.

Safety: live rows are never deleted (cross-root duplicates are reported, not
removed); writes stay inside the project (links out, a .claude outside the
project, hard-linked settings and user-scope files are refused per file, with a
once-per-state notice); the record is written only after the settings write is
verified; a lock with a 1 s wait and a lock-free fallback; minimal byte-level cuts
that keep indentation, CRLF and compact lines. A clean session start stays at
HEAD's ~37 ms.

Project-scope wiring no longer writes a personal config root's absolute path; it
uses the project install's path or the per-session ${CLAUDE_CONFIG_DIR:-...}
form. verify heals first, and wf-conform counts dead rows as failures, so a
project with dead wiring can no longer read "0 failed". The installer surfaces a
real wiring failure instead of piping it away.

Independent review ran five rounds: 10 defects (6 reproduced), then 9, then 8
low, then 3, then 2, each fixed and pinned. Mutants killed per round: 25/25,
44/44, 16/16, 6/6, 3/3. bin/prove --since HEAD 405/405, script-conformance
283/283, idempotence 9/9.

Also in this change:
- Stale "score" wording rewritten to what the code does; image-validator and
  ui-design CRIT-02 are verdicts with a reason, not undefined ratings.
- Two new link checks (every relative markdown link resolves; every
  "file § Section" citation names a file) caught seven dead references, fixed.
- PASS-DEAD-HOOK precision restated on its measured basis (38 of 38 on six
  projects), with the earlier false positive recorded.
- `ablate` is no longer described as a command in nine shipped references
  (org-chart-format.md follows in the next release, so this one needs no re-audit).
- Fact 2d recorded as having no preserved evidence file.
- script-conformance no longer inherits CLAUDE_CONFIG_DIR, so fixtures pass or
  fail the same for every account.
