Writing a handoff folds every other job folder into it, so old jobs no longer sit beside the new handoff

When you ask for a handoff, the handoff skill now reads every other folder under
.claude/workforce/jobs, including earlier handoffs whether picked up or not. It carries
each folder's unfinished work into the new handoff's Open items, naming the folder it
came from, and moves the files that work needs into from-<folder>/. Then it deletes the
old folder. A folder another live session holds stays where it is and is listed as held
by that session. A folder counts as held when its session's transcript in any Claude
account changed in the last hour. The working-files skill now says a handoff request
counts as your decision to delete (i17).
